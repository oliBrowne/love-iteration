# Love Iteration

Love Iteration is a private, local-first app for caring for a relationship through small, repeatable actions. One person can record check-ins, gratitude, memories, date ideas, and rituals. Sharing with a partner will be an explicit, opt-in feature added after the personal app is useful.

The repository is at day zero. [ARCHITECTURE.md](docs/ARCHITECTURE.md) defines the product and technical boundaries. [ROADMAP.md](ROADMAP.md) contains 360 ordered, small tasks. Run `node scripts/roadmap.mjs next` to see the next task and `node --test` to check the roadmap tooling.

Each completed task gets its own verified commit. The daily agent follows [AGENTS.md](AGENTS.md). No account, hosted service, or public site is required for the first 240 tasks.
